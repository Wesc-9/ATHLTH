# ATHLTH standard artwork

The app has 12 shared artwork slots used by Goals, Club headers, Club Events and Club Challenges.

Replace the placeholder `image.jpg` in any of these image sets with the final 2400 x 1200 JPG. Keep the filename exactly `image.jpg`; no Swift code or Contents.json changes are required.

- `ATHLTH/Assets.xcassets/GoalSprint.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalWalking.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalMountain.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalProgress.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalRelax.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalRunning.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalStrength.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalEndurance.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalRecovery.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalConsistency.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalEvent.imageset/image.jpg`
- `ATHLTH/Assets.xcassets/GoalAdventure.imageset/image.jpg`

Recommended export: JPG, sRGB, 2400 x 1200 px, 90–95% quality. Keep the important subject near the center because cards crop differently across iPhone and iPad.

Until a placeholder is replaced, ATHLTH intentionally falls back to an existing app hero image so users never see a 1 px placeholder.
