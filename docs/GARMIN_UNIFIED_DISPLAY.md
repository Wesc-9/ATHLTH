# Unified existing Garmin surfaces (private opt-in)
No Garmin add-on cards on Home or Insights and no separate history entry.
Existing sleep, steps and HRV tiles and Insights readiness measurement fields
can display current Garmin values with explicit attribution. Automatic
and Apple-first select Garmin only if Apple has no usable reading; Garmin-first
chooses Garmin when available. Account-scoped preference is stored locally.
Garmin values never reuse Apple trend charts or readiness baseline. Existing
history lists show both sources in chronological order with possible matches
labelled. Garmin details are read-only; no sharing or AI integration. No verified
cross-source identity yet, so possible duplicates are not deleted or summed.
Remaining: full historical Garmin metric coverage, actual unified readiness
and load, Home recent feed and weekly calendar, iPad studio, precise duplicate
reconciliation, approved commercial OAuth and real-account verification.
