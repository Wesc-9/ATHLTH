# Garmin in existing Home activity views
Private opt-in only. Garmin activities are typed as read-only private records
in the existing recent activity list and full activity log, not converted to
SocialPublishableWorkout. The same scope/activity filters and chronological
ordering apply. Compact views hide possible matches to local records; the full
ordinary WorkoutHistoryView retains both and marks candidates. No source data
is deleted. The Home weekly calendar marks recorded days and includes Garmin
rows in the selected day's existing completed-workout section. It does not
automatically mark a scheduled plan or community event as complete based on a
Garmin summary alone. The existing streak calculation unions calendar days,
not session counts. Garmin does not enter local/Apple training load totals or
Coach/competition/export/backup. Source-specific readiness and aggregation,
iPad training analytics, durable import and real account validation remain open.
