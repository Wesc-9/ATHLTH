# Unified Watch start
Use one Watch button beside iPhone. Tap uses the stored preferred live watch;
hold offers available watches without changing the default. Automatic chooses
one live-ready watch, or asks if multiple are ready. An unavailable explicit
default prompts rather than launching a different device. Device-local
preference is independent of health source preference. A Garmin Personal API
connection is read-only and never qualifies as a live-ready watch.
The shared quick-start bar supports an optional future Garmin action plus
readiness gate; Quick Run is still Apple-only for actual capture, retaining
its existing countdown/manual/delay options. Settings exposes the preference
and indicates Garmin sync-only when applicable. No Garmin start is simulated.
