## Lagring og tilgang

Kalender, drikkeplan og vedlikeholdsinnstillinger lagres lokalt per konto. Offlinepakker og dagbok ligger i ulike, kontodelte filmapper ekskludert fra backup. Dagboken inngår aldri i vanlig treningsbackup, AI-kontekst eller trener-snapshot. Kontoendring nullstiller synlige data og fjerner gamle kontoers påminnelser.

Trenerkoblinger, eksplisitt publiserte snapshots, tilbakemeldinger og frivillig partneravailability ligger i Supabase. Migrasjonen `20261004123729_athlete_tools_coach_and_partner_privacy.sql` aktiverer RLS, gir eksplisitte tabellrettigheter og bruker private, kontrollerte funksjoner med offentlige security-invoker-wrappere. Klientene får ikke direkte rettigheter til å endre trenerkoblinger eller skrive snapshots. Treneren kan ikke øke sitt eget delingsomfang.

## Kontrollene som skal bestå

- Apple-bygget og XCTest for eksisterende funksjoner samt nye tester for faser, baseline, fremtidige økter, progresjon, oppvarming, drikkeintervaller og vedlikehold.
- GPS-tester for korte ruter, begge endepunkter, sparsomme punkter som krysser skjulte områder, ugyldige payloads og begrenset punktantall.
- Full migrasjonsreplay i en midlertidig database med test av utøver/trener/uvedkommende, aksept, samtykkeeskalering, uønskede snapshotfelt, tilbakekalling, partnerpublisering, forfalsket eierskap og blokkering.
- Før App Store-publisering: kontroller skjermflytene på fysisk iPhone/Watch, varslingstillatelser og offlinepakker i flymodus. Ingen slik enhetstest er utført i dette Linux-miljøet.
